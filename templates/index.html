How should I organize my file?

The file must use ; as the separator.

The first column must be wavelength.

Each following column represents one sample.

Example:

wavelength;sample_1;sample_2;sample_3
180;15.1;43.21;12.2
180.125;39;32.2;15.4
180.250;21.5;18.7;30.1
...
  • ✓ First column: wavelength
  • ✓ First row: sample identification
  • ✓ Separator: ;
  • ✓ Each column after wavelength: one sample
  • ✓ Spectral data must be numeric
  • ✓ Accepted extensions: .dat and .csv
